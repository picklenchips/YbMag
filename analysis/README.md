# analysis/

Standalone scripts for processing and analyzing experimental data.

## Scripts

| File | Purpose |
|------|---------|
| `analyze_csv.py` | CSV data analysis (time-series, field sweeps) |
| `analyze_pixels.py` | Pixel-level image analysis from camera frames |
| `export_pixels_widget.py` | Widget for exporting pixel data from camera frames |

## Status

These scripts are currently standalone. The planned next step is integration into the main GUI (`app/`) as analysis panels. See the Next Steps section in [`../README.md`](../README.md).
